# Project Context

## Identity
RedCyberFox

## Purpose
An offline-first, passive-first OT security platform designed primarily for rural, small, and resource-constrained environments with older or low-spec Windows/Linux systems.

## Core Principles
- offline-first
- passive-first
- safety-first
- edge-light
- central-heavy
- low-resource operation
- deterministic and explainable security decisions
- no required paid SaaS for Alpha
- honest visibility limitations
