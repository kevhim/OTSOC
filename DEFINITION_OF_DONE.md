# Definition of Done

## General
- [ ] implementation complete
- [ ] unit tests
- [ ] integration/E2E tests where applicable
- [ ] error handling
- [ ] logs/metrics where appropriate
- [ ] documentation updated
- [ ] architecture rules respected
- [ ] resource impact considered
- [ ] offline behavior considered

## Security-critical
- [ ] negative/security tests
- [ ] no weakened validation
- [ ] audit behavior considered

## OT
- [ ] passive by default
- [ ] no production-path interference
- [ ] failure cannot affect control traffic
- [ ] false positives considered
- [ ] safety implications reviewed
